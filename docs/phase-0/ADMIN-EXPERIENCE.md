# Phase 0 — Admin Experience

## Admin navigation

```text
Content
├── Journeys
├── Assets
├── Translations
└── Review Queue
Membership
├── Users
├── Memberships
└── Knowledge Packages
```

## Journey management

Admin can list, create, edit, preview, publish, archive, inspect revisions, manage translations, organize Modules/Sections/Blocks, and attach assets.

## Access operations

Admin can inspect membership state, assign Packages, map Journeys to Packages, and review effective access. Package assignment does not edit content.

## Phase 0 UX rule

The interface may hide unavailable actions, but every action must be re-authorized server-side. Editor/reviewer role detail is finalized in Phase 1 implementation design.
