# Phase 0 — CMS Workflow

```text
DRAFT → REVIEW → PUBLISHED → ARCHIVED
```

- `DRAFT`: private and editable.
- `REVIEW`: submitted for editorial review; private.
- `PUBLISHED`: the only public revision.
- `ARCHIVED`: retained for history, not public.

English and Vietnamese progress independently. Published revisions are never edited in place. Archive is reversible and does not destroy history.

## CMS capabilities

Journey List, Create, Edit, Preview, Publish, Archive, Revision history, Translation management, Asset management, Review Queue, Knowledge Package management, Membership view, and Access view.

Advanced diff, rollback UI, notifications, and scheduled publishing belong to Phase 4.
