# Phase 0 — Product Vision

## Objective

Transform Banking BA Knowledge Hub into a Banking Knowledge CMS that can sell access by Journey. This phase defines the product boundary; it is not an LMS, course platform, or payment-gateway project.

## In scope

- Identity and account lifecycle
- Membership status
- Knowledge Packages and Journey access
- Journey CMS
- Sections, Modules, Blocks, translations, revisions, and assets
- Server-enforced published-content access

## Out of scope

Quiz, assignment, learning path, certificate, badge, learning analytics, course progress, community, video streaming, automated payment gateway, and per-section/per-block permissions.

## Roadmap

1. CMS Foundation: move ten Journeys from static source to CMS.
2. Knowledge Experience: navigation, search, reader, diagrams, API/reference and download experience.
3. Knowledge Access & Membership: packages, Journey grants, payment approval, and server enforcement.
4. Enterprise CMS: review queue, diff, rollback, audit, translation operations, and notifications.

## Phase 0 status

Product-first baseline. No Prisma schema, migration, or implementation contract is frozen here.
