# Datum Bank mockup asset provenance

Brand reference inspected in Chrome: https://datumhq.com/en/ (2026-10-26).

- `datum-logo-white.png`: original Datum Consulting logo downloaded from
  https://datumhq.com/wp-content/uploads/2025/04/logo_white.png (282 × 83).
  File is unchanged. The mockup clips the symbol with CSS and pairs it with
  the owner-requested **Datum Bank** text. The favicon wraps that same symbol
  in SVG with a dark-blue background; it is a concept adaptation.
- Primary blue `#315CD4` was sampled from rendered links/headings on the live
  reference. Dark navy and pale-blue supporting tones are mockup adaptations.
- Manrope was the live reference's computed font. Regular, semibold and bold
  files were downloaded from the `fonts.gstatic.com` URLs returned by:
  https://fonts.googleapis.com/css2?family=Manrope:wght@200..800&display=swap
- `Manrope-OFL.txt`: license from the Google Fonts Manrope directory:
  https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/OFL.txt

These files are used only in the local owner-requested banking concept. No
external asset request is needed when opening the served mockup.
